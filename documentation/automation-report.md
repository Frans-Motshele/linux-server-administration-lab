
# Linux Automation Report

## Objective
Automate disk and memory monitoring using cron.

## Tools Used
- Bash
- Cron
- Linux command-line utilities

## Scheduled Tasks

| Task | Frequency |
|---|---|
| Disk monitoring | Every 5 minutes |
| Memory monitoring | Every 10 minutes |

## Log Files
- logs/disk-monitor.log
- logs/memory-monitor.log

## Outcome
Both monitoring scripts were configured as scheduled
cron jobs. Their output is saved to separate log files
for later inspection.

## Skills Demonstrated
- Bash scripting
- Cron job scheduling
- Linux automation
- Log management
- System monitoring
